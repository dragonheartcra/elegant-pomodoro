# Changelog

All notable changes to this project are documented here. Versions follow
[SemVer](https://semver.org/).

## [Unreleased]

## [0.1.10] - 2026-09-29

### Changed

- Open-source readiness pass: removed upstream leftovers (updater remnants,
  dead `check_for_updates` setting, ghost i18n keys, `public.asc`,
  `openspec/`, upstream contributor/funding/security docs).
- New app icon and bilingual README (English / 简体中文).
- Release workflow rebuilt: unsigned artifacts, no updater manifest, no Scoop.

### Fixed

- Documentation drift: time units are seconds everywhere since MIGRATION_2.

## [0.1.9] and earlier

Development versions. Elegant Pomodoro started as a fork of
[Pomotroid](https://github.com/Splode/pomotroid) 1.7.1 (MIT), extended with
FlowTunes music channels and ambient sound mixing. See the repository history
for details.
